本项目是一款基于屏幕图像识别的 DGLab（郊狼）联动控制器。专为《永劫无间》等游戏设计，采用外部像素识别技术，不读内存，安全稳定。支持一键扫码绑定与透明框选区域。精准识别机制：护甲按蓝3格、紫4格、金5格、红6格逐格判定（支持半格），白/灰甲及无甲不触发电击；血量按白色填充比例识别。所有阈值与电击强度均可自定义，支持“一直电/间隔电”模式。自带置顶悬浮窗实时显示状态，切屏/识别不到血条时自动断电保护，并自动记忆上次设置，真正实现“开箱即用”的硬核体感反馈。


⚠️ 安全警告：请务必从最低强度（1~5）开始测试！本工具仅供个人娱乐，请确保在有人看管且意识清醒的情况下使用。


本软件基于最新的 WebSocket 协议开发，仅支持 DG-Lab App 4.0 及以上版本（郊狼 4.0）。如果您的手机端还是旧版 3.5 App，请前往官方应用商店或官网更新至最新版 4.0，否则无法扫码连接！
